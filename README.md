# HR Employee Analytics Dashboard

## Project Overview

The HR Employee Analytics Dashboard is an interactive data visualization project built to analyze employee data and provide insights into workforce distribution, attrition patterns, salary distribution, and departmental performance. The dashboard helps organizations understand their workforce better and make data-driven HR decisions.

This project demonstrates how business data can be transformed into meaningful insights using data visualization techniques.

## Objectives

The main objectives of this project are:

* Analyze employee distribution across different departments
* Identify attrition patterns in the organization
* Understand gender distribution within the workforce
* Analyze salary distribution among employees
* Provide interactive filters to explore HR data easily

## Tools and Technologies

The following tools were used to build this dashboard:

* Power BI for data visualization and dashboard development
* Microsoft Excel for dataset handling and preparation

## Dataset Information

The dataset contains HR-related employee information such as:

* Employee ID
* Department
* Gender
* Job Role
* Monthly Income
* Attrition Status

The dataset is used to analyze employee statistics and generate insights related to workforce analytics.

## Dashboard Features

The dashboard includes several key visualizations and metrics:

* Total Employees KPI
* Attrition Overview
* Average Salary KPI
* Employee Distribution by Department
* Gender Distribution
* Salary Distribution Analysis
* Department-wise Employee Count

Interactive filters allow users to explore the data by:

* Job Role
* Gender
* Department

## Key Insights

Some insights that can be derived from the dashboard include:

* Departments with the highest number of employees
* Attrition patterns across departments
* Salary distribution trends among employees
* Workforce gender distribution

These insights help HR teams identify trends and make strategic workforce decisions.

## Conclusion

The HR Employee Analytics Dashboard provides a clear and interactive way to analyze employee data. By using data visualization tools, complex datasets can be simplified into meaningful insights that support better decision-making.

This project demonstrates practical skills in data analysis, dashboard design, and business intelligence reporting using Power BI.
